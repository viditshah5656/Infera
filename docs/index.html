Minimal application example

Any OpenAI-compatible client can be pointed at the local gateway by changing the base URL.

from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8081/v1",
    api_key="local"
)

response = client.chat.completions.create(
    model="YOUR_MODEL",
    messages=[{"role":"user","content":"Hello from Infera"}]
)

print(response.choices[0].message.content)

Component responsibilities

Small details matter when you are deciding where a bug belongs.

Web interface

Lives in docs/ and is suitable for GitHub Pages. It discovers models, renders the conversation, sends browser requests, and provides explainers. It does not have permission to launch arbitrary programs.

Unified router

Owns the common API surface, CORS behavior, model discovery, routing, compatibility endpoints, and response streaming.

Backend adapter

Translates a common request into the dialect expected by a specific model backend and maps its response back into a compatible form.

Runtime services

These are the actual local processes doing inference or upstream web-backend communication. Their lifecycle belongs on the user's machine.

Installer

Packages setup into a repeatable first-run path. For trust, a mature release should additionally provide signed native installers and checksums.

Documentation

Architecture, security, contribution, attribution, and OpenAPI materials make the project inspectable instead of hiding behavior behind the UI.

Important network detail

Local-first does not automatically mean every upstream interaction is local.

Local surface: the default gateway binds to localhost. The browser talks to your machine, not to a hosted Infera inference service.
Adapter surface: some backends can communicate with provider/web services. That behavior depends on the adapter you choose and can change if an upstream service changes.

Models, names, and routing

Infera deliberately separates “what model the app asks for” from “how that model is reached”.

Gemini familyGateway routes matching model identifiers toward the Gemini adapter.
Qwen familyGateway can route Qwen identifiers toward a Qwen-compatible local service.
ChatGPT-styleIdentifiers matching the configured adapter can be forwarded toward the reverse-chatGPT service.
Unknown namesUnknown models should be treated as unsupported until a matching backend is available.
Why prefixes matter: routing rules can use model names as a compact dispatch mechanism. That keeps clients simple while the gateway owns backend selection.

Security & trust

This is where we should be unusually honest.

⌂

Local by default

The gateway's default host is 127.0.0.1. That reduces accidental exposure to other machines on the network.

✓

Open source

The source is inspectable on GitHub. Users can compare the installer, router, adapters, and docs rather than trusting a black box.

!

Installer reality

A browser cannot silently execute arbitrary local installers. First-run setup must be a user-initiated action; signed native installers are the long-term trust path.

Trust checklist

What a serious release should make easy to verify.

SourcePublic repository with clear attribution.
Release artifactVersioned installer with an immutable release tag.
ChecksumsSHA-256 values published alongside releases.
SigningWindows Authenticode and macOS Developer ID for mature installers.
SecretsCredentials and cookies should remain local and out of Git.
Network scopeClearly document which requests stay local and which adapters may reach upstream services.
AttributionCredit the original upstream project and explain Infera's additions.
Failure modeWhen the gateway is offline, the UI should say so instead of manufacturing a successful response.

LOCAL INSTALLATION

Run Infera on your machine

The browser cannot silently execute software. The first-run flow therefore starts with an explicit user download/run action. This page never asks you to paste credentials into the website.

Windows

Download the command launcher and run it. It fetches the trusted repository installer and starts the local services.

macOS / Linux

Download the shell installer, inspect it if you wish, then run it from your terminal.

Recommended trust workflow: inspect the public source, use versioned releases/checksums, and prefer signed native installers as the project matures.
WHAT IS INFERA?

A local control plane for AI

Think of Infera as the layer between your applications and your AI backends. It gives you one endpoint, one browser workspace, one model discovery surface, and one place to reason about compatibility.

It is not a hosted AI service

GitHub Pages serves the interface. The inference gateway runs locally on your machine.

It is not only a chatbot

The gateway is the reusable piece. The browser workspace is a polished client for it.

It is an adapter layer

Different model services can be presented through familiar API contracts.
