Install Infera once

GitHub Pages cannot silently execute programs on your computer. The first step is therefore a normal download. After installation, the website can use your local gateway without cloning the repository.

Windows · easiestDownload the launcher, then double-click the downloaded install.cmd. It bootstraps the local runtime for you.
macOS / LinuxDownload install.sh and run it from your terminal. The runtime is installed locally.
DevelopersOnly clone the repository when you want to build, modify or contribute to Infera.
