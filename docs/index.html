Why Infera feels different

A developer-facing control plane instead of another chat wrapper.

One boundary, many backends

Normalize provider-specific web behavior behind a single local gateway and familiar client interfaces.

Real streaming

Keep long-running generations alive with SSE streaming, event normalization and live connection visibility.

Local by default

The hosted control surface does not need to proxy model traffic. The gateway binds to localhost unless you intentionally change it.

Architecture

Protocol translation sits between your application and provider adapters.

The browser controls the local gateway. The hosted page is not the inference server.

Privacy boundary
The intended topology keeps the control surface public while the inference runtime stays local.
  • Hosted page serves UI only.
  • Gateway defaults to 127.0.0.1.
  • Credentials remain on the local machine.
  • Do not expose the gateway publicly without deliberate security controls.
